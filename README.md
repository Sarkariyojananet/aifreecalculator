# AI Free Calculator 🧮

A modern, fast, and responsive suite of 25+ free online calculators built with **Astro** and **Tailwind CSS**.

## 🌟 Features

- **25+ Real-Time Calculators**:
  - **Finance**: EMI, SIP, Income Tax, GST, Simple Interest, Compound Interest, Salary Take-Home, Discount, GDP
  - **Construction**: RCC Slab + Steel, Brickwork, Plaster, Concrete Breakup, Paint, RCC Beam, RCC Column, RCC Footing, Steel 12m Bars, Shuttering, Side Drain BOQ, Master Estimate
  - **Health**: BMI Calculator, Calorie Calculator, BMR Calculator
  - **General**: Age Calculator, Percentage Calculator, Universal Unit Converter, Height Converter, Weight Converter, Time Math, Date Difference
- **Zero Registration & 100% Client-Side Privacy**: Fast calculations right in your browser.
- **Dark Mode Support**: Anti-flicker theme persistence.
- **Full SEO & Social Meta**: Structured JSON-LD schema, OpenGraph, Twitter cards, and `robots.txt`.

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
